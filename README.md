# Аршин Скрин

Android-приложение для поиска сведений о поверке средств измерений во ФГИС «Аршин» и сохранения полной карточки в PDF.

## Параметры версии 1.0
- Поиск по заводскому номеру, поверителю и диапазону дат
- Выбор записи и формирование PDF со всеми доступными сведениями
- Локальная папка: «Протоколы поверки СИ»
- Папка Google Диска: «Протоколы поверки СИ»
- Сохранение: смартфон и Google Диск
- Загрузка по мобильной сети разрешена

Статус: подготовка Android-проекта. Подключение Google Диска и рабочая APK-сборка ещё не завершены.
